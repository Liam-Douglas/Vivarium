Vivarium · verification

Screen Check Runbook

Phase 5 rebuilt every screen's layout and was verified by type-checking and construction, never in a browser — the app needs Supabase credentials to render past sign-in. This is the pass that closes that gap.

1

Point it at Supabase

Two variables, read in src/lib/supabase.ts. The app throws on boot without them, so a blank screen here means the file is missing or misnamed.

# .env.local  — in the repo root
VITE_SUPABASE_URL=https://<your-project>.supabase.co
VITE_SUPABASE_ANON_KEY=<your anon/publishable key>

Use .env.local, not .env. .gitignore covers *.local, so .env.local cannot be committed by accident — a bare .env is not ignored and would be. The anon key is meant to be public, but a service-role key in a committed file is a real incident.

npm install
npm run dev        # http://localhost:5173
2

Seed a collection you can predict

Most of what changed only appears in particular states — an empty account shows almost none of it. Two fixtures generate a collection where every state is reachable, with dates written relative to the day you run them.

node scripts/make-test-fixtures.mjs busy
node scripts/make-test-fixtures.mjs quiet
# → fixtures/vivarium-busy.xlsx, fixtures/vivarium-quiet.xlsx

Sign up, create a household, then import one at /import (or Settings → Import, or More → Import on a phone). The sheets are named to match the app's own template, so the wizard classifies them without help.

  • busy — 2 overdue, 1 due soon, 1 due in two days, 1 on schedule, plus one animal with no feeding schedule and one never fed. Populates the Today queue and the untracked notice.
  • quiet — nothing due inside three days, so the queue empties and Coming up and Worth a look take over. Import into a second household, or delete the animals between runs.

Three states the importer cannot set, each a couple of clicks if you want them: a weight (log one on any animal, then the Overview sparkline and the growth chart appear), quarantine (edit an animal, set a quarantine start), and a medication course (Health tab → add a schedule with an interval and a start date, which is what puts a blue dose row in the queue).

Then the quiet fixture

If the Overdue tile is ever green while an animal has no schedule

That is the original false all-clear returning. It should read amber with “of N tracked”, and the untracked notice should name Ivy and Root. Both fixtures include those two animals precisely so this is checkable on every pass.

Fixtures are generated, not committed — regenerate them rather than reusing old files, since the dates are relative to the day they are made.
